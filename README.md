# Panda Slot Privacy Policy — GitHub Pages

## Publish
1. Create a **public** GitHub repository named `panda-slot-privacy`.
2. Upload `index.html` and `panda-icon.png` to the repository root.
3. Open **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. After deployment, the policy will be at `https://YOUR_GITHUB_USERNAME.github.io/panda-slot-privacy/`.
5. Open it on mobile and desktop, then paste that exact URL into **App Store Connect → Panda Slot → App Privacy → Privacy Policy URL**.

## IMPORTANT: Review before publishing
- Confirm that `info@lptech.forum` is a functioning company inbox and the listed legal address is accurate.
- Confirm the actual OneSignal SDK configuration and which device/usage events are sent.
- Confirm whether the game also uses analytics, crash reporting, ads, in-app purchases, accounts, or additional SDKs; update the policy accordingly.
- Confirm that notification consent and any required GDPR consent are implemented, not merely described.
- Confirm data retention, deletion handling, OneSignal contractual safeguards and international transfers with the responsible team.
- Confirm age rating and region-specific requirements for simulated gambling.
- Have legal/privacy counsel review before launch. A website alone does not ensure GDPR or Apple compliance.

## App Store Connect
The App Privacy data collection questionnaire must reflect the actual released build, including third-party SDK collection. Do not select 'Data Not Collected' merely because the game has no registration.
